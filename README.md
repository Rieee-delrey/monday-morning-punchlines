A program that writes one joke about Monday mornings to /output/entry.txt for make.fun's Monday Morning Punchlines bounty. The line was picked by sim-judging eight candidate punchlines pairwise against the kit's exact judge brief, in both orders, and keeping only a winner with a clear margin.

## Run it

```sh
python3 main.py
```

It writes the joke to /output/entry.txt (creating the directory if needed) and checks the file back: at most 200 characters, a single line, no leading or trailing whitespace.
